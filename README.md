# GTA：大清合伙人 · 互动电影 Demo

以紫禁城劫案为背景的视频驱动互动游戏，使用原生 HTML、CSS 和 JavaScript，无需安装 npm 依赖或构建工具。

需要单独下载 assets/videos 视频里的资源之后才能体验！！直接下载项目不能下载视频大文件，需要用 Git LFS 下载！！

进入游戏需要用按 ECS，然后选择 3 4 5 章节就能体验了！

## 启动

直接双击 `index.html`，使用现代桌面浏览器打开，点击「故事」进入游戏。页面内嵌剧情数据，直接打开本地文件也能运行。

也可在本目录运行 `python -m http.server 8000`，然后打开浏览器访问本地 8000 端口。服务器模式读取同目录 JSON；直接打开文件时使用内嵌数据。

## 操作

| 按键 | 功能 |
| --- | --- |
| W | 按住前进／驾驶，松开暂停视频 |
| Tab | 射击片段先选择微型冲锋枪，松开确认装备 |
| 鼠标左键 | 装备后按住射击，松开暂停；射击片段使用此键 |
| E | 互动、确认或接受支线 |
| Q | 忽略可选支线 |
| Alt、1／2／3 | 按提示选择当前允许切换的角色 |
| Space | 测试模式下立即完成当前片段，保留后续交互 |
| Esc | 暂停，或在菜单中选择游戏进程 |
| J | 查看本局剧情记录 |
| M | 声音开关 |
| F | 全屏 |
| H | 显示／隐藏场景测试面板与控制台校验按钮 |

右击右上角金额可临时修改显示数值，不改变剧情账目。重开或跳转进度后恢复剧情金额。

## 当前内容

包含国库得手、分头撤离、夹道交火、夺取御驾、可选瓜摊支线、接应同伴、装甲车突围和结算。瓜摊支线可以接受或跳过，两条路径均可完成本章。

已有三段视频，原画面和音轨保留：

| 文件 | 内容 |
| --- | --- |
| assets/videos/cart_alley.mp4 | 安春晓推车撤离 |
| assets/videos/shoot.mp4 | 选择武器后射击，八发子弹耗尽 |
| assets/videos/carjack.mp4 | 年灼华夺取御驾并驶离 |

其余八个有效剧情视频片段尚未补齐，显示深灰背景和所缺文件名，可用 Space 推进；这些占位不影响完成游戏流程。标题视频、旧的接近御驾片段与独立警报／切人音效也尚未提供，当前使用已有界面和视频音轨。

`preview-config.js` 控制混合视频测试：`quickStep` 为 `true` 时允许快速推进；已补齐的片段设置 `useVideo: true`。所有视频补齐后，可将 `enabled` 设为 `false` 使用剧情 JSON 中的完整视频配置。

标题页保留在线字体样式表；网络不可用时回退到系统字体，游戏操作不依赖网络服务。

背景音乐使用 `assets/audio/background-music.aac`，默认音量为 20%，自动循环播放。打开页面时尝试自动播放；浏览器如限制有声自动播放，点击「故事」或与页面交互后开始。背景音乐持续跨场景播放，松开 W 暂停视频时不会打断音乐。M 或画面上的声音开关同时控制视频原声与背景音乐；自动校验期间一并静音，结束后恢复此前的声音设置。默认音乐音量可在 `game-music.js` 中调整。

## 文件结构

```text
index.html                  游戏入口
game.js                     剧情、视频播放与输入处理
style.css                   标题页、开场和基础界面
game-hud.js / .css          游戏内 HUD、角色轮盘与任务横幅
game-radar.js               连续导航、小地图与暂停地图
game-weapon.js              装备选择
game-console.js             可选自动校验与诊断日志
game-music.js               自动循环背景音乐与声音开关
preview-config.js           测试播放配置
characters.json            角色数据
map.json                    地图数据
story.json                  剧情数据
missions/heist_stage01.json 第一章任务
runtime/                    导航、任务卡、图标和武器绘图模块
assets/                     视频、角色图片、标题图片与场景图片
```

## 修改剧情与校验

直接打开文件时，`game.js` 中的 `EMBEDDED_STORY`、`EMBEDDED_MISSION`、`EMBEDDED_CHARACTERS` 和 `EMBEDDED_MAP` 提供数据。修改外部 JSON 后，需要同步相应内嵌对象；也可使用本地服务器读取外部 JSON。

按 H 打开测试面板，选择「从头自动校验」，或在浏览器控制台调用 `QingTest.run()`；`QingTest.stop()` 停止校验。校验会从头运行并临时静音，完成后停在结算。日志反映实际游戏状态，支持保存。
